# TAPVERIO v2 — сайт, анимации и портфолио IT-студии

Адаптивный HTML/CSS/JS сайт: сайты, Telegram-боты и Mini Apps для бизнеса Минска и Беларуси. Готовая демонстрация для презентации услуг потенциальным клиентам.

## Новое в v2

- Премиальные CSS-анимации первого экрана: stagger-появления, градиентный заголовок, плавное движение телефона, орбиты и плавающие уведомления.
- Scroll-reveal анимации для секций, карточек и тарифов; индикатор прокрутки. Уважает `prefers-reduced-motion`; без JavaScript контент видим.
- Карточки портфолио с мягкой 3D-реакцией на курсор и подсветкой. На сенсорных экранах без 3D-эффекта.
- Фильтры портфолио (Все / Mini Apps / Сайты).
- `portfolio.html` — отдельная страница с тремя проектами и детальным описанием.
- **Честная маркировка**: ATELIER STORE — интерактивное демо, FORMA STUDIO и SLOT. BOOKING — визуальные концепты, не заказы реальных клиентов.
- Все дополнительные эффекты лежат в `effects.css` и `motion.js`, чтобы существующую логику магазина не трогать.

## Что работает

- Презентация услуг и тарифы: сайт от 1 100 BYN, Mini App магазин от 1 800 BYN, индивидуальный проект от 3 500 BYN.
- Интерактивный демонстрационный магазин в макете смартфона: каталог, поиск, категории, корзина, изменение количества, демонстрационный заказ, выбор доставки и необязательные комментарии.
- Форма заявки **не отправляет данные на сервер**. Она формирует сообщение для копирования и, если задан Telegram, открывает ссылку на профиль.
- Адаптивная вёрстка; изображения товаров — локальные SVG.
- Отдельная папка brand-kit с векторными вариантами логотипа.

## Настройка перед публичным запуском

1. Проверьте и зарезервируйте публичный Telegram username. **`@tapverio` сейчас НЕ подтверждён свободным и НЕ подключён автоматически.**
2. В `config.js` пропишите `telegramUsername: 'ваш_реальный_ник'` (без @). Нельзя указывать чужой username.
3. Проверяйте домен через реестр и регистрируйте только доступный вам вариант. В HTML не зашит несуществующий адрес сайта.
4. Проверьте тарифы и условия, добавьте политику конфиденциальности и юридические реквизиты по необходимости перед коммерческим запуском.
5. Если нужно получать заявки автоматически, подключите backend / Telegram-бота с серверным хранением токена. Токен нельзя размещать в фронтенд-коде.

## Открыть локально

Откройте `index.html` в браузере. Портфолио доступно из меню и по `portfolio.html`. Для полноценного тестирования через локальный сервер:

```bash
cd TAPVERIO-website
python -m http.server 8080
```

Откройте http://localhost:8080.

## Публикация

**GitHub Pages (без backend)**: загрузите все файлы проекта в корень репозитория, в Settings → Pages выберите main/(root). После публикации получите публичную ссылку. Можно прикрепить домен после регистрации.

**Railway**: проект поддерживает Dockerfile, можно подключить GitHub-репозиторий и создать публичный адрес после деплоя.

## Ограничения демонстрационной версии

Сайт не обрабатывает оплаты, не отправляет заявки и демо-заказы в Telegram и не хранит личные данные на сервере. Все заказы внутри телефона — исключительно демонстрация UI.

## Советы по портфолио

Когда появятся реальные клиенты, заменяйте концепты на настоящие кейсы только с их согласия. Укажите задачу, вашу роль, реализованные функции, ссылки на результат и проверенные показатели (если доступны). Не создавайте вымышленные отзывы и результаты.
